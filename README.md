## 😫 你一定也遇過這種崩潰瞬間

- 🎮 **打遊戲打到關鍵會戰**：畫面突然定格 2 秒，再恢復時角色已經在溫泉看黑白畫面。
- 🎬 **剪片、打字、寫程式**：滑鼠指針突然像卡進泥巴裡一樣掉幀轉圈。
- 😤 **氣急敗壞按下 `Ctrl + Alt + Del`**：打開工作管理員時，CPU 卻悠哉躺在 3%，風平浪靜，根本找不到剛才是誰在暴衝！

> 💡 **為什麼平常抓不到？**  
> 因為 Windows 內建的工作管理員只能看到**「現在這一秒」**的狀態；但卡頓往往是**「剛才那 1~2 秒瞬間暴衝」**，當你打開視窗時，兇手早就偷吃完收工了！

## 🌟 PulseGuard 幫你做什麼？三大殺手級功能

### 1. 📼 60 秒卡頓黑盒子（隨時時光倒流抓兇手）
就像行車記錄器一樣，隨時保全過去 60 秒的硬體數據。
**只要感覺電腦卡了一下，按下鍵盤 <kbd>Space</kbd> 空白鍵**，它立刻幫你回溯剛才那幾十秒是誰突然霸佔 CPU、把記憶體吃滿、或是狂操硬碟。

### 2. 🤖 自動抓兇哨兵（不用盯著螢幕，它幫你拍照存證）
掛在背景完全不佔資源。只要偵測到電腦異常掉幀、CPU 飆高或網路爆 Ping，**它會自動拍下「案發現場證物照」**，並用**大白話告訴你到底該怎麼做**（不用看一堆天書般的數字）。

### 3. 🎈 桌面純透明懸浮球（小巧置頂，一按回血）
一個極簡無邊框的透明小圓球飄在螢幕角落：
- **看數字**：隨時看目前記憶體使用率。
- **左鍵點一下**：瞬間釋放閒置記憶體，讓電腦喘口氣。
- **右鍵選單**：一鍵開啟診斷面板、抓剛才卡頓兇手或查毒。

## 🚀 3 秒快速上手

不需要複雜設定，跟著以下步驟直接執行：

### 步驟 1：下載並解壓縮專案
將專案下載或解壓縮到電腦的任意資料夾中。

### 步驟 2：點兩下啟動
直接雙擊執行資料夾內的：
```text
start.bat
```
- 腳本會自動檢查環境（若缺少套件會自動補齊）。
- 啟動完成後會自動幫你打開瀏覽器，顯示 PulseGuard 監控面板！

### 步驟 3（可選）：開啟桌面懸浮小圓球
若你想在平時使用時隨時看記憶體與一鍵釋放，雙擊執行：
```text
run_floating_ball.bat
```
螢幕右上角就會出現半透明置頂小球，不擋視線又隨手可用。

## 💡 最常見問題：微軟防毒吃滿 CPU 怎麼辦？

很多使用者的自動哨兵都會抓到一個叫 **`MsMpEng.exe` (Antimalware Service Executable)** 的程序突然吃掉 70%~100% CPU，電腦直接卡死。

### 為什麼會這樣？
那是 Windows 內建防毒軟體。微軟常常在你打遊戲或工作時，偷偷在背景啟動「自動排程掃描」，或者它跟你正在讀寫的大量檔案「互咬」，導致多核心處理器瞬間被吃滿。

### 🛠️ 兩招徹底解決：

#### 方法 A：最速應急（工作管理員降速）
1. 按鍵盤 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Esc</kbd> 叫出**【工作管理員】**。
2. 切換到**【詳細資料】**頁籤。
3. 找到 `MsMpEng.exe`，按右鍵 ➔ **【設定優先順序】** ➔ 改為**「低」**。
4. 這樣它就只能在電腦閒置時運作，再也不會搶奪你正在打遊戲或剪片的資源！

#### 方法 B：一勞永逸（加入排除資料夾）
1. 打開 Windows「設定」➔ 搜尋**【Windows 安全性】**。
2. 點入**【病毒與威脅防護】** ➔ 點擊「病毒與威脅防護設定」下方的**【管理設定】**。
3. 滾動到最下方找到「排除項目」➔ 點擊**【新增或移除排除項目】**。
4. 把你平時放工作專案、程式碼、遊戲或暫存檔的資料夾加入排除名單。
5. 搞定！防毒從此不再死磕這些檔案，根治突發性卡頓。
