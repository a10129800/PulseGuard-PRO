主要卡頓兇手：微軟防毒 (MsMpEng.exe)

【為什麼會卡？】微軟 Windows Defender 原生防毒程式正在全力掃描磁碟與檔案，把 CPU 運算能力吃到了 100%。這是防毒軟體在查毒時的正常現象，並不是電腦中毒！

推薦步驟 1 等它掃描完畢（約 1~2 分鐘）：防毒查完之後，CPU 會自動降回 5%~10%，電腦就會恢復完全順暢。
應急步驟 2 按右上角【一鍵急救減負 (R)】：強制釋放閒置記憶體，讓系統立刻騰出空間給其他軟體使用。
立即止卡 3 若剛才有啟動微軟查毒：可點擊「防毒安全中心」分頁中的「中止掃描」按鈕，立即解除 CPU 佔用。
